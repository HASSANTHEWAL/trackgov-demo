# TrackGov demo

Live demo of TrackGov, a website for monitoring government vehicles and their fuel use.
Made for the class expo of Pengembangan Aplikasi Berbasis Web (SIF302), Universitas Islam Indonesia.

**All data is simulated.** Vehicles, drivers, trips and refuels are dummy data. The road routes are
real (OpenStreetMap); trip times and stops are simulated. The login is a demo: choose a role, no password.

Plain HTML, CSS and JavaScript. The only library is Leaflet 1.9.4 for the maps.

This repository only holds the published website. The project itself is developed in a private repository.
